# SensoGrid v1 contract

Implement in this worktree. User authorized implementation without confirmation for routine decisions. Web Push OPTIONAL; local monitoring independent. No commits/push/deploy.

## HTTP API
Base /api. JSON errors {detail:string}. All configuration/data endpoints require HttpOnly session cookie. Public GET /health, GET /api/auth/status and POST /api/auth/setup, POST /api/auth/login. First-run setup creates sole initial administrator with username/password; disable after first user; rate-limit auth; enforce trusted same-origin on mutating authenticated requests (Origin if supplied, disallow cross-site, credentials no wildcard CORS). Credentials scrypt hash, random hashed server sessions expiring. Logout POST /api/auth/logout. GET /api/auth/me => {id,username}. Auth status => {setup_required:boolean,authenticated:boolean,user:{id,username}|null}. Password min12.

GET /api/dashboard => {mode:"demo"|"ble"|"off",now:ISO UTC,average_temperature:number|null,average_humidity:number|null,sensors:SensorView[],rooms:RoomView[],status:{collector:string,storage:string,last_error:string|null}}.
SensorView {id,name,address:string|null,protocol:"lt_thermometer",room_id:string|null,enabled:boolean,sample_interval_seconds:number,last_seen:string|null,temperature:number|null,humidity:number|null,rssi:number|null,available:boolean,battery_raw:number|null}. RoomView {id,name,temperature:number|null,humidity:number|null,available:boolean}.
GET /api/sensors => SensorView[]. POST /api/sensors {name,address,room_id?,protocol?} => SensorView. PATCH /api/sensors/{id} {name?,room_id?,enabled?,sample_interval_seconds?}. DELETE /api/sensors/{id}; reject deletion where needed or clear floorplan references atomically.
POST /api/sensors/discover => {devices:[{name,address,rssi,protocol,service_uuids,manufacturer_data,service_data}]}. Discovery duration15s; no automatic addition.
GET /api/rooms => RoomView[]. Room edits use floorplan import/editor full PUT.

GET /api/floorplan => Floorplan. PUT /api/floorplan Floorplan => Floorplan (atomic validated save, stable IDs).
POST /api/floorplan/preview Floorplan => {valid:true,rooms:number,sensors:number,warnings:string[]}; no writes. GET /api/floorplan/export => same JSON download.
Floorplan {schema_version:1,id:string,name:string,units:"m",width:number,height:number,rooms:[{id:string,name:string,polygon:[number,number][] }],sensors:[{sensor_id:string,room_id:string|null,x:number,y:number}]}.
Reject duplicate IDs, invalid/nonfinite/out of bounds or self-intersecting polygons (<3 distinct points/zero area), unknown sensors/rooms and mismatched sensor assignments. Room rename/layout updates preserve history and stable IDs. Removed rooms are retained as archived metadata for historic joins. Distinguish room assignment stored on measurement from current assignment.

GET /api/history?start=ISO&end=ISO&bucket=raw|hour|day|week|month&room_ids=id1,id2&sensor_ids=id1,id2 => {points:[{timestamp,sensor_id,room_id,temperature,humidity,temperature_min,temperature_max,humidity_min,humidity_max,count}],source:"demo"|"influxdb3"}. Server aggregation. Timezone UTC. No fabricated samples when actual history unavailable. Max query span366days, window chunk<=48h for Core, cap points.
GET /api/settings => {language:"cs"|"en",theme:"light"|"dark"|"system",temperature_unit:"C"|"F",push_enabled:boolean,heatmap:{temperature:[number,number,number],humidity:[number,number]}}. PATCH merges & validates.
GET /api/system/settings => {sample_interval_seconds:900,stale_after_seconds:1800}; PATCH validates & persists system configuration (admin).
GET /api/system/status => {mode,collector,storage,last_error,push_available:boolean}.
GET /api/alerts/rules => Rule[]. POST /api/alerts/rules RuleInput. PATCH /api/alerts/rules/{id}. DELETE /api/alerts/rules/{id}.
Rule {id,name,sensor_id:string|null,room_id:string|null,metric:"temperature"|"humidity"|"offline",operator:"above"|"below",threshold:number,duration_seconds:number,reset_threshold:number,enabled:boolean}. Exactly one target; offline threshold interpreted minutes.
GET /api/alerts/events => [{id,rule_id,rule_name,state:"active"|"resolved",message,started_at,resolved_at:string|null}]. Persist pending/active state across restarts; hysteresis and duration; no repeated notifications while active; stale readings cannot trigger temperature/humidity rules.
GET /api/push/key => {available:boolean,public_key:string|null}; POST /api/push/subscriptions {endpoint,keys:{p256dh,auth},label?:string}; DELETE /api/push/subscriptions with {endpoint}; POST /api/push/test. Validate push endpoint URLs to avoid SSRF/private destinations, encrypt? store as necessary but never log keys. Optional pywebpush with VAPID from env; cleanup410/404; notifications independent of browser being open. Settings UI subscribes per browser.

## Root-owned runtime modules (backend/sensogrid/runtime.py, timeseries.py, ble/)
Runtime(settings, db). async start(), stop(). current() -> list[Measurement dict]. state property dict{collector,storage,last_error}. async discover()->list[device dict]. async history(start:datetime,end:datetime,room_ids:list[str],sensor_ids:list[str],bucket:str)->list[history point dict].
Measurement dict: {sensor_id,room_id,timestamp,temperature,humidity,rssi,battery_raw,source}.
DB contract provided by backend agent: db.all_sensors()->list[dict] (Sensor fields except live readings); db.system_settings()->dict; db.note_seen(sensor_id,iso_timestamp)->None. DB calls synchronous, bounded SQLite (own short connections). Runtime must keep no historical measurements in SQLite. db.seed_demo() called by API only mode=demo.
Settings provided by backend agent (Pydantic BaseSettings env_prefix SENSOGRID_): mode demo|ble|off default demo, data_dir Path default ./data, influx_url default http://localhost:8181, influx_token:str default "", influx_database default sensogrid, sample_interval_seconds int default900, stale_after_seconds int default1800, diagnostics bool defaultFalse, vapid_private_key str default"", vapid_public_key str default"", vapid_subject str default mailto:admin@example.invalid, secure_cookies bool defaultFalse, session_hours int default168, static_dir Path default frontend/dist absolute via env in container. Need Settings accessible as sensogrid.config.Settings.
Agent API main: create_app(settings:Settings|None=None,runtime_factory=Runtime) -> FastAPI and app=create_app(). Startup init DB, demo seeds iff mode=demo, runtime.start; shutdown runtime.stop; independent periodic alert evaluation. Test runtime inject avoids BLE/Influx.
Production Compose mode=ble; local demo clearly labeled, simulated data never substitute for real failures.

## Frontend direction
Vue3+TS strict+Vite+Tailwind4, vue-router, vue-i18n cs/en, ECharts+vue-echarts, PWA. Self-host fonts/no CDNs. Distinct climate-instrument identity: cool gray #f2f5fa, ink #142238, cobalt #315efb; navy dark variant. Dominant SVG plan workspace, system sans with monospaced numeric readouts. Horizontal desktop navigation, bottom navigation mobile. Compact centered authentication on a measurement grid; no split green login composition. Pages Dashboard, History, Floorplan editor, Alerts, Settings, first setup/login. Responsive accessible. No wall of generic cards. Empty/loading/error/offline/demo states truthful. Poll dashboard30s paused hidden. SW cache application shell only (never /api/private data); web push service worker. Shared floorplan renderer. Editor polygons, vertex drag, room drag/resize, grid/snap, meter dimensions, sensor placement/assignment, undo/redo, zoom/pan touch. Timeline history colors; history comparison toggles chart data series, presets24h/7d/30d/custom, min/max/avg, missing data as gaps. Imports preview then explicit apply; export Blob. Settings sensor scan/add/configure/delete and PWA installation prompt. Celsius values on wire; convert display only.
