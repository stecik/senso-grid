# SensoGrid 1.0.0

První stabilní vydání lokálního monitorování teploty a vlhkosti.

- Česká/anglická Vue PWA s dashboardem, historií, půdorysem a editorem místností.
- Průběžný příjem nešifrovaných BTHome v2 reklam z Xiaomi LYWSD03MMC s ATC firmwarem, bez GATT spojení.
- Lokální účty a nastavení v SQLite, historie v InfluxDB 3 Core, trvalá fronta při výpadku databáze.
- Pravidla upozornění, volitelný Web Push, diagnostický export a stav baterie.
- Verzionovaný Docker image `ghcr.io/stecik/sensogrid:1.0.0` pro Linux amd64.

## Nasazení a upgrade

Produkční stack a HTTPS nginx konfigurace jsou v repozitáři [HomeServer_infra](https://github.com/stecik/HomeServer_infra/tree/main/sensogrid).
Před upgradem zastav oba kontejnery a zazálohuj volumes `sensogrid_app_data`, `sensogrid_influx_data`, `.env` a offline admin token InfluxDB. Zachovej také případné VAPID klíče.
Verze InfluxDB zůstává `3.12.0-core`; schéma konfigurace ani historie se tímto releasem nemění.
Po nasazení ověř `/health`, přihlášení a nové BLE vzorky. Starý image a zálohu uchovej pro rollback.

BLE vyžaduje Linux host s BlueZ a systémovým D-Bus. Šifrovaný BTHome ani stock Xiaomi MiBeacon nejsou podporované. Web Push vyžaduje samostatné VAPID klíče.
