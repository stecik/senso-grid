# SensoGrid 1.0.1

Oprava barvy systémového horního pruhu v nainstalované PWA.

- V tmavém režimu se systémový pruh zbarví stejnou tmavě modrou jako hlavička aplikace.
- Barva pruhu reaguje na zvolený vzhled aplikace i změny systémového tématu.
- PWA manifest i úvodní HTML používají shodnou tmavě modrou barvu při spuštění aplikace.

Docker image: `ghcr.io/stecik/sensogrid:1.0.1` (Linux amd64). Databázové schéma se nemění.
Po nasazení aplikaci otevři online, aby se načetl aktualizovaný PWA balíček. Na konkrétním telefonu je potřeba ověřit barvu systémového pruhu.
